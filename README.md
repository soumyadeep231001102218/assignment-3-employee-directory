# Assignment 3: Employee Directory

This is a React-based web application that displays and manages employee information using React State and Events. 

## Features
- **Add Employee**: Create new employee records.
- **Edit Employee**: Modify existing employee details.
- **Delete Employee**: Remove employees from the directory.
- **Search**: Filter employees by Name or ID.
- **Department Filter**: Filter employees by their respective departments.
- **Employee Count**: Displays the total number of filtered employees.
- **Persistent Storage**: Data is saved to `localStorage` so it persists across reloads.
- **Modern UI**: Clean and intuitive interface with a premium dark mode design.

## Employee Data Managed
- Name
- Employee ID
- Department Name
- Gender
- Phone Number
- Local Address
- Permanent Address

## Setup Instructions

To run this project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/soumyadeep231001102218/assignment-3-employee-directory.git
   ```

2. Navigate into the project directory:
   ```bash
   cd assignment-3-employee-directory
   ```

3. Install the dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open your browser and visit the live deployment to view the site: [https://soumyadeep231001102218.github.io/assignment-3-employee-directory/](https://soumyadeep231001102218.github.io/assignment-3-employee-directory/)
